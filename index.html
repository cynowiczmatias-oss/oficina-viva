Ajustes

La clave queda guardada solo en este iPhone y se usa únicamente para hablar con Anthropic. No la compartas con nadie.

  1. Entrá a console.anthropic.com y creá una cuenta.
  2. En Billing cargá algo de saldo (con unos pocos dólares alcanza para mucho).
  3. En API Keys tocá "Create Key", copiala y pegala acá.

Cambialo cuando quieras. Para el día a día, Sonnet rinde muy bien.

Tus datos

Tareas y chats se guardan en este iPhone. Si borrás los datos de Safari o desinstalás la app, se pierden.
